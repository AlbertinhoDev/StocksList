# StockList

`StockList` - iOS-приложение для просмотра списка акций, поиска компаний и тикеров, а также сохранения избранных позиций локально на устройстве.

Проект написан на `UIKit`, использует `MVP` для основного экрана, `Coordinator` для навигации, получает данные из удаленного JSON API и сохраняет избранное через `Core Data`.

## Возможности

- загрузка списка акций с удаленного API
- отображение тикера, названия компании, логотипа, текущей цены и дневного изменения
- поиск по тикеру и названию компании
- быстрый выбор популярных и недавних запросов
- переключение между экранами `Stocks` и `Favourite` с анимацией
- локальное сохранение избранного через `Core Data`
- полностью программный интерфейс и портретная ориентация

## Архитектура

Проект разделен на несколько уровней:

- `App/Application` - жизненный цикл приложения, координаторы, константы, ресурсы
- `App/Screens/Main` - основной экран: `View`, `Presenter`, `Models`, `Protocols`
- `App/Packages/Core/Services/Network` - сетевой слой и декодирование
- `App/Packages/Navigation` - абстракции маршрутизации
- `App/Packages/DesignSystem` - цвета, шрифты, UI-хелперы и layout-константы
- `CoreData` - слой локального хранения и модель данных

Сценарий запуска приложения:

1. `SceneDelegate` создает `AppCoordinator`
2. `AppCoordinator` инициализирует `NavigationRouter`
3. `FlowCoordinator` собирает основной модуль через `ScreenBuilder`
4. `MainPresenter` загружает данные и обновляет экран

## Поведение основного экрана

Основной экран содержит:

- поисковую строку с поведением скрытия при скролле
- панель кнопок для переключения между списком акций и избранным
- таблицу с карточками акций
- коллекцию популярных и недавних поисковых запросов

`MainPresenter`:

- запрашивает данные по адресу `https://mustdev.ru/api/stocks.json`
- загружает логотипы компаний
- преобразует ответ API в `StockCellModel`
- синхронизирует состояние избранного с локальным хранилищем

## Локальное хранение

Избранные акции сохраняются в `Core Data` в сущности `StockListCoreData`.

Сохраняемые поля:

- `nameOfStock`
- `nameOfCompany`
- `favourite`

Это позволяет восстанавливать выбранные позиции после повторного запуска приложения.

## Требования

- `Xcode` с установленным iOS runtime
- минимальная версия iOS: `15.6+`
- доступ к интернету для загрузки акций и логотипов

## Запуск

1. Откройте `StockList.xcodeproj` в `Xcode`
2. Выберите схему `StockList`
3. Выберите `iPhone` simulator или реальное устройство
4. Нажмите `Run`

Дополнительная установка пакетов, настройка переменных окружения и API-ключи не требуются.

## Важные файлы

- `StockList/App/Application/Constants.swift` - размеры UI, URL API и данные для поисковых подсказок
- `StockList/App/Screens/Main/MVP/View/MainViewController.swift` - логика экрана и обработка пользовательских действий
- `StockList/App/Screens/Main/MVP/Presenter/MainPresenter.swift` - загрузка, преобразование данных и обновление избранного
- `StockList/App/Screens/Main/MVP/Presenter/Network/StocksApiService.swift` - работа с API
- `StockList/CoreData/CoreDataManager.swift` - локальное хранение избранного

## Текущие ограничения

- URL API захардкожен в `Constants.swift`
- блоки популярных и недавних запросов статические
- в проекте нет автоматизированных тестов
- отдельный экран деталей акции пока не реализован

## Заметки по разработке

- основной интерфейс собран полностью в коде
- проект использует собственный `DesignSystem` для шрифтов, цветов и UI-элементов
- в репозитории есть `.xcworkspace`, но для текущего проекта достаточно `StockList.xcodeproj`, так как внешние менеджеры зависимостей не подключены
